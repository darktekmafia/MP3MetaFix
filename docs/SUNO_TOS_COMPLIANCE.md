# Suno.com Integration & Terms of Service Compliance

**Current As Of**: September 2026  
**Governing Policy**: [Suno Inc. Terms of Service & Acceptable Use](https://suno.com/terms)  
**Status**: Compliant — Public Read-Only Metadata Hydration  

---

## 1. Executive Summary

MP3MetaFix provides an on-demand metadata enricher and artwork synchronizer for audio tracks generated by users on Suno.com. 

This document defines the architectural boundaries and legal compliance posture of MP3MetaFix with respect to Suno’s Terms of Service (ToS). **MP3MetaFix does not utilize unofficial generation APIs, does not bypass paywalls or authentication, does not consume user credits, and does not perform automated catalog scraping.**

## 3. How the Integration Operates Technically

### A. Public Web Page Hydration (Link Preview Model)
When a user uploads an MP3 with an embedded Suno comment tag (`made with suno; ... id={uuid}`) or inputs a public song link (`https://suno.com/song/{uuid}`):
1. The backend performs a standard HTTP GET request to the public web page URL that the creator published.
2. The server parses the public Server Component payload (`self.__next_f.push`) and OpenGraph meta tags (`og:title`, `og:image`) already delivered publicly to any web browser or link-unfurling bot (e.g., Discord, Twitter/X, Telegram, Slack).
3. The extracted fields (Title, Artist Handle, Style Tags, Lyrics, Cover Art URL, Year, Model Version) are presented to the user in a non-destructive selective merge table.

### B. SSRF & Security Safeguards
* **Strict URL Regex**: Target URLs are strictly validated to conform to RFC 4122 UUIDv4 patterns (`[a-f0-9]{8}-[a-f0-9]{4}-[a-f0-9]{4}-[a-f0-9]{4}-[a-f0-9]{12}`).
* **Domain Whitelisting**: Artwork downloads (`POST /api/suno/apply-artwork`) are strictly restricted to verified Suno CDN domains (`cdn1.suno.ai`, `cdn2.suno.ai`, `cdn-o.suno.com`).
* **Image Bounds**: Downloaded images are processed through Pillow with strict decompression bomb defenses (`MAX_IMAGE_PIXELS = 10,000,000`, max 4096×4096px).

## 4. Periodic Review & Maintenance Checklist

To maintain compliance as Suno's platform evolves, maintainers must verify:
1. **No Introduction of Authentication Hooks**: Never introduce endpoints that ask users for Suno account passwords, session cookies, or authorization bearer tokens.
2. **No Automated Batch Catalog Crawling**: Ensure batch tools in MP3MetaManager only query Suno metadata for files explicitly loaded into the user's local workspace.
3. **OpenGraph Fallbacks**: Maintain fallback support for standard HTML `<meta>` tags so metadata extraction continues to function without reliance on internal stream structures.
4. **Terms of Service Monitoring**: Review Suno's published Terms of Service at major release milestones or upon platform updates.
